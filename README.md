# 🧠 EEG Signal Classification Project

This repository contains the final B.Sc. project, which focuses on classifying EEG signals using machine learning and deep learning models.  
The project includes two main Jupyter notebooks, each dedicated to a different classification task using EEG data.

---

## 📁 Files

### 1. Mental State Classification
This notebook focuses on classifying EEG signals to determine the mental state of individuals — relaxed, focused, or distracted.  
It uses EEG data from healthy volunteers (e.g., eyes open vs. eyes closed) and applies ML models to classify based on EEG patterns.

**Key steps include:**
- Data preprocessing (artifact removal, normalization)
- Feature extraction
- Training and evaluation of classification models
- Performance metrics for model evaluation

### 2. Epilepsy Classification
This notebook classifies EEG signals for epilepsy detection.  
It includes EEG data from epileptic patients and healthy individuals, distinguishing between seizure, non-seizure, and normal activity.

**Key steps include:**
- EEG signal preprocessing (artifact removal, filtering)
- EEG data segmentation (seizure vs non-seizure)
- Applying machine learning models to classify seizure activity
- Evaluation and comparison of model performance

---
